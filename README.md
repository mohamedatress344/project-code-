# Smart Cane Navigation System

This repository contains the source code and documentation for our Smart Cane graduation project.

## Project Overview
The system is designed to help visually impaired users navigate inside the faculty using voice-guided instructions and smart navigation logic.

## Features
- Voice-guided navigation
- Floor and destination selection
- Real-time movement instructions
- Return-to-gate mode
- Arduino-based embedded system
- Audio feedback system

## Hardware Requirement for Testing
The code is directly connected to the smart cane hardware components.  
Therefore, a complete and accurate test can only be performed when both the hardware and software are available together.

The system depends on:
- Sensors
- Arduino boards
- Audio modules
- Buttons and navigation inputs
- Real-time hardware interaction



## Important Note

Our project is a hardware-based system, so it must be tested using the real smart cane hardware components.

For accurate testing and evaluation, the project should be demonstrated physically in the college or during the discussion session, because the system depends on real-time interaction between the hardware and the software.
